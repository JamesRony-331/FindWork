## 一致性检查

| 检查项 | 概念设计 | 最终实现 | 结论 |
| --- | --- | --- | --- |
| 整体色彩 | 深青蓝导航、冷灰蓝背景、白色工作区、青绿色强调色 | 通过全局 token 统一复现 | 一致 |
| 页面骨架 | 固定侧栏、顶部用户栏、标题区、主体数据区 | 用户端 11 个页面共用 `UserLayout` | 一致 |
| 信息密度 | 紧凑筛选器、指标条、表格和图表并列 | 控件高度、间距和字体统一为研究台风格 | 一致 |
| 组件形态 | 小圆角、细边框、弱阴影，无渐变和玻璃效果 | 面板 6–8px 圆角，阴影仅用于浮层级区域 | 一致 |
| 数据表达 | 指标、排行、趋势、分布、明细表联合表达 | ECharts 图表配合原生表格、排行和筛选器 | 一致 |
| 岗位页导航 | 概念图曾混入管理端入口 | 实现严格只保留普通用户导航 | 有意修正，符合需求 |
| 首页概览 | 概念图包含地图和日期筛选 | 概览页改用城市表格与柱状图，完整筛选放在各分析页 | 有意简化，避免重复功能 |
| 响应式布局 | 概念图以桌面端为主 | 390px 下侧栏折叠为图标栏，指标和图表改单列，无页面横向溢出 | 扩展实现 |

## 数据组织检查

- 页面演示数据、筛选项和业务函数均放在 `src/data` 对应模块中。
- 列表、指标、导航、筛选项和消息记录均通过变量及 `v-for` 渲染。
- Vue 文件只负责布局组合、响应式绑定及路由/DOM 适配，后续接入后端时可替换数据模块的赋值或请求逻辑。
- 管理端页面未纳入本次实现，保留给后续若依管理端工程。
