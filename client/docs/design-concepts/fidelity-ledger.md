## 一致性检查

| 检查项 | 概念设计 | 最终实现 | 结论 |
| --- | --- | --- | --- |
| 整体色彩 | 深青蓝导航、冷灰蓝背景、白色工作区、青绿色强调色 | 通过全局 token 统一复现 | 一致 |
| 页面骨架 | 固定侧栏、顶部用户栏、标题区、主体数据区 | 用户端 11 个页面共用 `UserLayout` | 一致 |
| 信息密度 | 紧凑筛选器、指标条、表格和图表并列 | 控件高度、间距和字体统一为研究台风格 | 一致 |
| 组件形态 | 小圆角、细边框、弱阴影，无渐变和玻璃效果 | 面板 6–8px 圆角，阴影仅用于浮层级区域 | 一致 |
| 数据表达 | 指标、排行、趋势、分布、明细表联合表达 | ECharts 图表配合原生表格、排行和筛选器 | 一致 |
| 岗位页导航 | 概念图曾混入管理端入口 | 实现严格只保留普通用户导航 | 有意修正，符合需求 |
| 首页概览 | 概念图包含地图和日期筛选 | 概览页改用城市表格与柱状图，完整筛选放在各分析页 | 有意简化，避免重复功能 |
| 响应式布局 | 概念图以桌面端为主 | 390px 下侧栏折叠为图标栏，指标和图表改单列，无页面横向溢出 | 扩展实现 |

## 数据组织检查

- 页面演示数据、筛选项和业务函数均放在 `src/data` 对应模块中。
- 列表、指标、导航、筛选项和消息记录均通过变量及 `v-for` 渲染。
- Vue 文件只负责布局组合、响应式绑定及路由/DOM 适配，后续接入后端时可替换数据模块的赋值或请求逻辑。
- 管理端页面未纳入本次实现，保留给后续若依管理端工程。

## 主页改造补充检查

| 检查项 | 设计依据 | 实现结果 |
| --- | --- | --- |
| 首屏层级 | 清晰说明平台价值，并突出核心操作 | 左侧标题、说明和主次按钮，右侧为看板预览 |
| 看板视觉 | 沿用深青蓝、白色面板和青绿色数据强调 | 指标、趋势与城市排行保持同一视觉语言 |
| 核心跳转 | 主页可直接进入数据看板 | “进入数据看板”指向 `/user/dashboard`，浏览器点击验证通过 |
| 数据组织 | 演示内容应便于后续替换为接口数据 | 指标、趋势、城市、功能入口及说明均来自 `home.js` |
| 响应式 | 手机端保持可读并避免横向滚动 | 390px 下看板改单列，页面宽度与视口一致 |
| 图标处理 | 图标风格与现有导航一致 | 统一使用 `AppIcon` 线性 SVG，包括方向箭头 |

## 系统动态展示页检查

| 检查项 | 确认稿依据 | 浏览器实现 |
| --- | --- | --- |
| 首屏构图 | 左侧超大标题与 CTA，右侧抽象数据图形 | 1280 × 900 首屏保持同一左右比例和视觉重心 |
| 色彩与字体 | 深青蓝底、青绿色图形、少量黄绿色强调 | 颜色完全沿用既定 token，无紫色、渐变或玻璃效果 |
| 动态表现 | 数据图形运动、信息流动、滚动分区渐显 | 圆环旋转、柱图生长、跑马灯、指针视差及 IntersectionObserver 渐显均已启用 |
| 内容顺序 | 岗位、薪资、城市、AI 四段明暗交替 | 四个主题分区依照确认稿顺序和明暗节奏实现 |
| 页面路径 | 展示页可返回主页并进入数据看板 | `/` → `/showcase` → `/user/dashboard` 已在浏览器实际点击验证 |
| 数据组织 | 重复内容由结构化数据驱动 | 分区、指标、排行、跑马灯和页尾证明项均来自 `showcase.js` 并使用 `v-for` |
| 移动适配 | 保留强排版与图形主体 | 390 × 844 无横向溢出，主 CTA 可见，四个主题分区均存在 |
| 动效降级 | 减少动态偏好下保持可访问 | `prefers-reduced-motion` 会禁用持续动画并直接显示内容 |
